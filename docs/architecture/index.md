# 架构文档索引

> 上级索引：[工程文档](../index.md)

## 范围

本分类记录 Janus 的组件、进程模型、模块边界、存储布局，以及 macOS 应用的结构。Run 与任务的状态规则归入[领域](../domains/index.md)，对外接口和事件格式归入[接口](../interfaces/index.md)。

## 文档列表

- [架构概览](overview.md)：设计原则、组件、模块划分、启动顺序和一次 Run 的数据流。阅读时机：第一次修改编排器，调整模块职责或启动流程，或需要了解请求如何从应用走到 ACP 子进程。
- [数据模型与存储](data_model.md)：Janus home 中的数据、SQLite 表、Run 快照、产物和早期版本留下的数据。阅读时机：修改 `backend/src/db.rs`、数据目录结构、产物保存或快照内容。
- [ACP 适配器管理](adapters.md)：适配器清单、按版本存放、按需安装、安装步骤、检查更新、升级与回滚、对运行中会话的影响。阅读时机：修改 `backend/src/adapters.rs`、新增内置运行时，或排查适配器安装和升级问题。
- [macOS 应用](frontend.md)：应用与 Janus 服务的关系（连接或启动包内服务、端口被占用）、源码结构、由事件推导状态、同步方式、页面、请求卡片和会话中的消息。阅读时机：修改 `frontend/`，或新增、修改需要在应用中展示的事件。
