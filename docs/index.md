# Janus 工程文档

> 这是 Project Doc 根索引。加载 project-doc skill 后，在本仓库的第一个任务中完整阅读本文件，再按「阅读时机」进入相关分类。已读内容按 skill 的「阅读与上下文复用」规则复用；内容缺失或需要刷新时再重读。

## 文档范围

本库记录需要跨多个代码位置才能理解的 Janus 工程知识：编排器的组件与数据流、Run 与任务的状态机、目标模式和共享看板、Agent 与角色的权限模型、HTTP / SSE / MCP / ACP 接口、事件格式、配置、运维、测试、安全边界和重要设计决策。仓库只放代码，运行数据、依赖、配置和日志都在 Janus home（`~/.janus`）。单个函数就能看懂的实现细节、工作进度和临时方案不在本库内。代码中的 `@project-doc docs/<路径>.md#<章节 ID>` 注释指向解释该代码的章节，修改那段代码前先读对应章节。

`README.md` 是产品入口，不属于本库；本索引和分类文档只记录当前工程事实。

- [领域](domains/index.md)：Run 生命周期、目标模式与共享看板、Agent / 角色 / 工作区与权限模式。阅读时机：涉及 Run 或任务状态、调度、重试、验证、交付、恢复、主控行为、协作者提问、权限模式或角色配置。
- [接口](interfaces/index.md)：HTTP API、事件、看板 MCP 工具、ACP 集成和配置项。阅读时机：改动路由、Run 操作、事件类型或字段、MCP 工具、ACP 请求与 `_meta`、环境变量或 `config.toml`。
- [运维](operations/index.md)：部署方案（目录规范、安装、服务、升级）、运行手册、测试、安全边界。阅读时机：安装、启动、升级或卸载 Janus，修改 `justfile`、CI 工作流或打包脚本，发布版本，排查失败的 Run，运行或编写测试，评估隔离与凭据风险；合并任何改动前读其中的「Agent 变更的经验教训」。
