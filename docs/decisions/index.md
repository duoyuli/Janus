# 决策记录索引

> 上级索引：[工程文档](../index.md)

## 范围

本分类保存架构决策记录（ADR）：背景、决策、取舍和后果。当前系统行为以架构、领域、接口和运维文档为准；ADR 回答「为什么这样做」。已经被取代的决策保留在历史区，不能作为开发依据。

新增 ADR 时至少写明状态、背景、决策、取舍、后果和相关文档；取代旧决策时，在新 ADR 中注明，并把旧 ADR 标为 `superseded`。

- [事件是唯一事实来源](events_as_source_of_truth.md)：状态变化先写成只追加的事件，界面、看板和恢复都从事件推导。阅读时机：想引入独立的状态表、修改事件格式，或调整恢复方式之前。

- [权限交给 Agent 原生模式](agent_native_permissions.md)：角色直接选择 Agent 声明的权限模式，Janus 不再有自己的读写开关，也不做校验。阅读时机：想在 Janus 层面增加权限控制，或修改角色的权限设置之前。
- [任务直接在工作目录中运行](in_place_workspaces.md)：关闭并删除独立 worktree，所有任务在工作区目录中读写。阅读时机：想重新引入 worktree、调整 diff 产物或并发写入策略之前。
- [主控以 /goal 推进目标](goal_mode_lead.md)：主控用 `/goal` 自主推进，按需协作，只能是 Claude Code 或 Codex。阅读时机：修改主控的启动方式、交付条件，或想让其他 Agent 担任主控之前。
- [用户数据、依赖和日志都放在 Janus home](user_home_layout.md)：仓库只放代码，数据库、适配器、产物、配置和日志都在 `~/.janus`。阅读时机：新增要写盘的功能，或想改变数据、依赖、日志的存放位置之前。
- [ACP 适配器按需安装，按版本存放](on_demand_adapters.md)：第一次用到时安装，每个版本一个目录，原子切换，可升级和回滚。阅读时机：修改适配器的安装、升级方式，或新增适配器来源之前。
- [按验收标准自行验证](criteria_over_commands.md)：每个任务写验收标准，执行者用自己判断的方式逐条验证并给出证据，Janus 只核对结构，不运行验证命令。阅读时机：想让 Janus 执行验证命令、修改验收或结果核对的方式之前。
- [用原生 macOS 应用做展示层](native_macos_app.md)：界面只有 SwiftUI 应用，通过 HTTP API 读写，包内带 Janus 服务和 Node.js，CI 打 DMG 发布，只做 ad-hoc 签名。阅读时机：想改变应用与服务的关系、增加其他界面、调整打包签名，或修改事件推导之前。
- [通过 MCP 看板协作](board_over_mcp.md)：编排先校验后执行，主控与协作者通过内置 MCP 看板交换任务、进展、阻塞和提问。阅读时机：修改看板工具、编排校验或主控与协作者之间的信息流之前。
