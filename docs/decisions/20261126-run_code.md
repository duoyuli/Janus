# ADR：MCP 路由的代码模式：Janus 运行模型写的脚本，Agent 可以把脚本存进资源库

- 状态：已采纳（accepted），记录于 2026-11-26。
- 相关文档：[ADR：MCP 路由照 magpie 只给三个工具](20261126-mcp_router_three_tools.md)、[资源库：MCP 路由](../domains/20261116-resource_library.md#mcp_router)、[安全边界：资源库](../operations/20261031-security.md#library)。

## 背景

magpie 的 MCP 路由有第三个工具 `run_code`：模型写一段 JavaScript，在脚本里调用路由背后的工具，只交回脚本返回和打印的内容。需要连续调用几次、或只要一个大结果中的一部分时，一次调用代替多次，用不上的结果不进上下文。资源库里带 `code.js` 的 Skill 可以在脚本里当函数调用；跑通的脚本可以用 `save_as` 存成一个 Skill。用户要求按 magpie 的方式做，代码模式默认开，`save_as` 存下的 Skill 给所有数字员工。

这扩大了信任边界（合并前检查第 5 条）：Janus 进程要运行模型写的代码，Agent 能往资源库里写东西。

## 决策

1. **在单独的进程里运行**：脚本在 QuickJS（`rquickjs` 0.14，锁定在 `Cargo.lock`）里运行，没有文件、网络、子进程、定时器、`require` 和 `import`。运行它的是 Janus 自己的程序，以隐藏子命令 `janus run-code-helper` 再启动一次（`coderun`）：清空环境变量，经 stdin 和 stdout 的 JSON 行收脚本、请求工具调用、拿回结果。脚本能碰到的只有路由给这个会话的工具，每次调用和 `call_tool` 走同一条路，各记一条 `mcp.routed`。
2. **限制照 magpie**：一段脚本最多调用 100 次工具，同时最多 8 个；总共最多 50 秒；QuickJS 的内存上限 512 MB；交回的日志和结果各截到 40000 字节。到时间还没结束时，父进程在 2 秒后结束辅助进程；Agent 取消请求时脚本立刻停止，正在进行的调用一起取消。
3. **带代码的 Skill**：资源库的 Skill 在 `SKILL.md` 旁边有 `code.js`（最多 256 KB）时，`run_code` 里可以用 `skills.<名字>(args)` 调用它的默认导出。`run_code` 的说明列出这个会话能调用的此类 Skill（最多 30 个），`janus-skills` 的目录里也标出它们。
4. **`save_as`**：脚本没有出错地跑完时，按 `save_as {name, description}` 存成一个在 Janus 中新建的 Skill：`SKILL.md` 写明怎样经 `run_code` 调用，`code.js` 是这段脚本。和其他资源一样，它给所有数字员工，从下一个 Run 起可用。同名的 Skill 拒绝保存，不覆盖。存下后全局事件流发 `library`，应用重新读资源库。
5. **开关**：资源库的 MCP 标签有「代码模式」开关，默认开（`configs` 中 `mcp_router` 一行，没有这一行时视为开）。关掉后路由只给 `find_tools` 和 `call_tool`，`instructions` 也不再提 `run_code`。

## 取舍

- **用 Janus 自己的程序作辅助进程，不用 Node**：不依赖用户装了什么，也不新增下载来源；QuickJS 有自己的内存上限，单独的进程再挡住解释器中断不了的内置函数（例如超长的 `repeat`）。
- **工具调用绕过 Agent 逐个工具的确认**：Agent 的权限只决定能不能调用 `run_code`。这和 `call_tool` 相同，见 [ADR：MCP 路由照 magpie 只给三个工具](20261126-mcp_router_three_tools.md) 的取舍；每次真实调用照旧有记录。
- **Agent 写进资源库，不经用户确认**：存下的 Skill 会被以后的每个数字员工看到和调用。magpie 是单人工具，存给保存它的那个 Agent；Janus 没有「给谁用」，只能给所有人。用户接受这一点：存下的 Skill 和其他 Skill 一样出现在资源库，可以编辑或删除；它只能调用路由的工具，能做的事不超过模型直接调用这些工具。
- **代码模式关掉时，带代码的 Skill 不能运行**：`janus-skills` 仍会列出它们；它们只是普通的说明加一段代码。

## 后果

- 新增 `backend/src/coderun.rs`、`coderun/script.rs`、`coderun/prelude.js`，以及集成测试 `backend/tests/coderun.rs`（启动真实的辅助进程）。`main` 在解析其他参数之前先识别隐藏子命令。
- 资源库新增 `App::skill_code`、`save_code_skill`、`code_mode` 和 `save_code_mode`；`PUT /api/library/router`；`GET /api/library` 多一个 `mcpRouter.code`；编辑在 Janus 中新建的 Skill 时保留它的 `code.js`。
- [安全边界](../operations/20261031-security.md#library)的「资源库」一节写明代码模式运行的是什么、能碰到什么。
